    Seguridad y Grupos

    En Odoo, la seguridad se gestiona principalmente mediante:

    1. Usuarios (res.users)
    2. Grupos (res.groups)
    3. Permisos de acceso (ACL)
    4. Reglas de registro (Record Rules)

    El diseño de seguridad permite controlar:

    • Qué modelos puede usar un usuario
    • Qué operaciones CRUD puede realizar
    • Qué registros concretos puede ver
    • Qué elementos de la interfaz aparecen

    En este documento veremos cómo implementar seguridad en el módulo:

    task_app

    sobre el modelo:

    task_app.task_model

    Categorías de Seguridad

    Las categorías agrupan los grupos dentro del formulario de usuarios.

    📄 security/task_security.xml

    <odoo>

  <record id="task_app_security_category" model="ir.module.category">
    <field name="name">Task App</field>
    <field name="description">Access rights for Task App</field>
    <field name="sequence">10</field>
  </record>

</odoo>

    Esta categoría aparecerá en:

    Ajustes → Usuarios y Empresas → Usuarios

    Definición de Grupos

    En task_app definiremos dos roles:

    Grupo Rol
    Task User Usuario funcional
    Task Manager Responsable / Jefe de equipo

    Grupo Task User

    📄 security/task_security.xml

    <odoo>

  <record id="group_task_user" model="res.groups">
    <field name="name">Task User</field>
    <field name="category_id" ref="task_app.task_app_security_category"/>
    <field name="implied_ids" eval="[(4, ref('base.group_user'))]"/>
  </record>

</odoo>

    ✔ Hereda los permisos básicos de usuario interno (base.group_user)

    Grupo Task Manager

    <odoo>

  <record id="group_task_manager" model="res.groups">
    <field name="name">Task Manager</field>
    <field name="category_id" ref="task_app.task_app_security_category"/>
    <field name="implied_ids" eval="[(4, ref('task_app.group_task_user'))]"/>
  </record>

</odoo>

    ✔ Todo Manager es también User, gracias a implied_ids.

    Permisos de acceso (ACL)

    Los permisos de acceso controlan operaciones CRUD sobre modelos:

    Permiso Acción
    perm_read Leer
    perm_write Editar
    perm_create Crear
    perm_unlink Borrar

    📄 security/ir.model.access.csv

    id,name,model_id:id,group_id:id,perm_read,perm_write,perm_create,perm_unlink
access_task_user,access_task_user,model_task_app_task_model,task_app.group_task_user,1,1,1,0
access_task_manager,access_task_manager,model_task_app_task_model,task_app.group_task_manager,1,1,1,1

    Interpretación

    Grupo Leer Crear Editar Borrar
    Task User ✔ ✔ ✔ ❌
    Task Manager ✔ ✔ ✔ ✔

    👉 El borrado queda restringido a Managers

    Reglas de Registro (Record Rules)

    Las ACL controlan el modelo
    Las record rules controlan qué registros concretos puede ver un usuario.

    Objetivo

    Grupo Acceso
    Task User Solo sus tareas
    Task Manager Todas las tareas

    📄 security/task_rules.xml

    <odoo>

  <record id="task_rule_user_own" model="ir.rule">
    <field name="name">Task - User Own Records</field>
    <field name="model_id" ref="model_task_app_task_model"/>
    <field name="groups" eval="[(4, ref('task_app.group_task_user'))]"/>
    <field name="domain_force">[('responsible_id', '=', user.id)]</field>
  </record>

  <record id="task_rule_manager_all" model="ir.rule">
    <field name="name">Task - Manager All Records</field>
    <field name="model_id" ref="model_task_app_task_model"/>
    <field name="groups" eval="[(4, ref('task_app.group_task_manager'))]"/>
    <field name="domain_force">[(1,'=',1)]</field>
  </record>

</odoo>

    Requiere en el modelo:

    responsible_id = fields.Many2one("res.users", string="Responsible")

    Seguridad en la interfaz (vistas)

    Odoo permite mostrar elementos solo a ciertos grupos.

    Menú solo para Managers

    <menuitem
  id="menu_task_manager"
  name="Gestión Avanzada"
  parent="task_app.menu_task_root"
  groups="task_app.group_task_manager"
/>

    Botón restringido a Managers

    <button
  name="action_finalize"
  type="object"
  string="Finalize Task"
  groups="task_app.group_task_manager"/>

    Campo visible solo para Managers

    <field name="internal_flag" groups="task_app.group_task_manager"/>

    Flujo de Seguridad

    flowchart TD

U[Usuario] --> A{Tiene group_task_manager?}

A -->|Sí| B[ACL completas]
A -->|No| C[ACL limitadas]

B --> D[Puede borrar tareas]
C --> E[No puede borrar tareas]

C --> F[Solo ve sus registros]
B --> G[Ve todas las tareas]

    Resumen general

    Capa Qué controla Ejemplo
    Grupo Rol funcional Manager
    ACL Operaciones CRUD Borrar tareas
    Record Rule Qué registros Solo los suyos
    Vista UI visible Botones/menús

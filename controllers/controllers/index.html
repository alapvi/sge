    Web Controllers y API

    Ejemplos con task_app

    En Odoo, además de las vistas estándar (form, tree, kanban, etc.), podemos exponer endpoints HTTP/JSON propios mediante Web Controllers.
    Esto nos permite, por ejemplo:

    • Crear una API REST-like para nuestro módulo task_app.
    • Exponer datos a otras aplicaciones (frontends, móviles, otros servicios).
    • Crear páginas web personalizadas (públicas o privadas).

    En esta sección nos centraremos en usar controllers como API, con ejemplos basados en task_app.

    Conceptos básicos

    Módulo y estructura

    Para usar Web Controllers en task_app, debemos:

    1. Crear un directorio controllers/ dentro de nuestro módulo.
    2. Añadir un __init__.py en controllers/.
    3. Crear un fichero Python, por ejemplo controllers/task_controller.py.

    Estructura típica del módulo:

    task_app/
  __init__.py
  __manifest__.py
  models/
    __init__.py
    task_model.py
  controllers/
    __init__.py
    task_controller.py
  views/
  security/
  ...

    En __init__.py de la raíz del módulo:

    from . import models
from . import controllers

    En controllers/__init__.py:

    from . import task_controller

    Módulo odoo.http y objeto request

    Para definir un controlador web usamos:

    from odoo import http
from odoo.http import request
    • http.Controller: clase base para definir controladores.
    • @http.route(...): decorador que define una ruta HTTP.
    • request: objeto que representa la petición actual (usuario, entorno, parámetros, etc.).

    Decorador @http.route: parámetros clave

    @http.route(
    '/ruta',              # patrón de URL
    type='http'/'json',   # tipo de respuesta
    auth='public'/'user'/'none',
    methods=['GET','POST'],
    csrf=True/False,
    cors='*' / origenes
)

    Parámetros importantes

    • type
    • http: devuelve HTML o texto.

    • json: devuelve JSON (Odoo serializa el retorno).

    • auth

    • public: usuario público sin login.
    • user: requiere usuario autenticado.

    • none: sin sesión (gestión manual de seguridad).

    • methods

    • Lista de métodos HTTP permitidos.

    • csrf

    • Protección anti-CSRF.

    • cors

    • Permite peticiones desde otros dominios.

    Ejemplo 1: API JSON — Listar tareas (GET)

    Modelo base:

    class TaskModel(models.Model):
    _name = "task_app.task_model"

    name = fields.Char()
    description = fields.Text()
    is_done = fields.Boolean(default=False)
    responsible_id = fields.Many2one("res.users")

    Controlador:

    class TaskController(http.Controller):

    @http.route('/task_app/api/tasks', type='json', auth='user', methods=['GET'], csrf=False)
    def get_tasks(self, **kwargs):
        Task = request.env['task_app.task_model'].sudo()
        tasks = Task.search([])

        return [
            {
                'id': t.id,
                'name': t.name,
                'description': t.description or "",
                'is_done': t.is_done,
            }
            for t in tasks
        ]

    Ejemplo de consumo:

    curl -X POST \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"call","params":{}, "id":1}' \
  http://localhost:8069/task_app/api/tasks

    Ejemplo 2: Crear tareas (POST)

    @http.route('/task_app/api/tasks/create', type='json', auth='user', methods=['POST'], csrf=False)
def create_task(self, **kwargs):

    name = kwargs.get('name')
    description = kwargs.get('description', '')

    Task = request.env['task_app.task_model'].sudo()
    task = Task.create({
        'name': name,
        'description': description,
    })

    return {'id': task.id, 'name': task.name}

    Ejemplo 3: Cambiar estado (POST)

    @http.route('/task_app/api/tasks/<int:task_id>/toggle_done', type='json', auth='user', methods=['POST'], csrf=False)
def toggle_done(self, task_id, **kwargs):

    Task = request.env['task_app.task_model'].sudo()
    task = Task.browse(task_id)

    task.is_done = not task.is_done
    return {'id': task.id, 'is_done': task.is_done}

    API HTML opcional (website)

    @http.route('/task_app/tasks', type='http', auth='user', website=True)
def tasks_page(self, **kwargs):
    tasks = request.env['task_app.task_model'].sudo().search([])
    return request.render('task_app.tasks_page_template', {'tasks': tasks})

    Seguridad

    • auth='user' → respeta permisos del usuario
    • auth='public' → acceso abierto
    • sudo() → eleva permisos
    • csrf=False → necesario en APIs externas
    • cors='*' → habilitar CORS si hace falta
